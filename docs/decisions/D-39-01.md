# D-39-01: Review editor Return confirmation policy

- Status: accepted and implemented; automated candidate validation complete; installed Release UAT pending
- Date: 2026-08-23
- Issue: #39
- Supersedes: D-38-01's editable-review bare-Return editing rule only
- Retains: D-38-01's original-target capture, clipboard lifecycle, capture/journal production,
  recognition/retry/replay consumption, and independent review-axis decisions

## Context

The historical Issue #38 contract made the review editor multiline and assigned bare Return to text
editing. The shipped
review surface now routes Return at the native AppKit editor boundary so confirmation cannot be
mistaken for ordinary text insertion, while preserving multiline editing and the existing review
authority boundaries.

## Decision

- In an editable review, unmodified Return and keypad Enter confirm the current exact draft once.
- Shift+Return and Shift+Enter insert one LF and never confirm.
- Command+Return remains the compatibility confirmation shortcut.
- Return while the editor has marked IME text is passed to the input method; the review shortcut does
  not consume that composition event.
- The `输入` button confirms. `取消`, Escape, and closing the editable window discard without target
  or pasteboard mutation. A whitespace-only draft remains editable but cannot confirm.

This decision changes only editable review UI keyboard routing. Captured target identity and
selection, confirmation delivery and clipboard restoration, capture/journal production,
recognition/retry/replay consumption, and the independent review axis are unchanged. The recording
overlay remains status-only, and compatibility mode remains governed by D-27-01.

## Consequences and verification boundary

The review editor remains multiline and keeps native selection, undo, scrolling, and IME behavior;
only the unmarked Return path is now a confirmation authority. Command+Return remains available for
existing users and keypad Enter follows the same unmodified/Shift/Command policy as the main Return
key.
